# LoreLink shared design foundations

Shared theme and typography for the management portal and the public documentation site.

## Themes

- `lorelink` (default light)
- `lorelink-dark` (`data-theme` plus class `dark`)

## Rules

- Typography: IBM Plex Sans (UI/body), IBM Plex Serif (wordmark and headings), IBM Plex Mono (code).
- Accent comes from the gold mark. Primary is ink in light, gold in dark.
- Portal is an operational workspace. Docs are a reading layout.
- No second UI library.
